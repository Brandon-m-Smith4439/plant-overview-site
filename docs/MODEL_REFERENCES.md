# Machine Model References

This document records the visual and manufacturer research introduced in version 0.3.0 and retained by the editable procedural machine system in version 0.7.0.

The renderer creates recognizable block models for plant-history visualization. It does **not** reproduce proprietary engineering geometry, internal mechanisms, installation clearances, service zones, or foundation requirements.

## KODIAK 10-45 polisher

**Confidence: high for the general exterior profile; approximate dimensions in the viewer.**

Reference characteristics used:

- Long horizontal polishing and mitering body
- Ten-spindle layout represented by the blue front motor bank
- Long conveyor/track bed
- Raised operator/control console
- White and gray enclosure with dark lower frame

- https://hhhglassequipment.com/product/kodiak-10-45-flat-polishing-and-mitering-machine/

## Future accuracy improvements

The most useful next inputs would be:

1. Vendor model numbers and technical sheets.
2. Overall length, width, and height for each installed machine.
3. Photos from front, rear, both sides, and a raised three-quarter view.
4. Distance from known plant columns or surveyed floor coordinates.
5. Required maintenance and operator-clearance zones.
